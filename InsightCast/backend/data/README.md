# InsightCast V1 Data

Runtime data goes here during local development: SQLite database files, generated daily briefs, run logs, and temporary exports.

Default generated paths:

- SQLite database: `data/insightcast.sqlite3`
- Markdown daily briefs: `data/briefs/YYYY-MM-DD-insightcast-brief.md`
- myHarness trace files: `data/traces/{run_id}.jsonl`
- myHarness checkpoint files: `data/checkpoints/{checkpoint_id}.json`
